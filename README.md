# 🚀 MOONCRUST // PIXEL AI STUDIO & COMMAND CENTER

Aplikasi web Mission Control Dashboard bergaya **2D Pixel Art & Retro Isometric Game** dengan **5 Autonomous Specialist Sub-Agents** yang bergerak, berinteraksi, dan siap diperintah bekerja secara mandiri maupun dalam rantai tugas (*5-Stage Auto-Pipeline*).

---

## 🌟 5 Karakter Sub-Agent & Spesialisasi Tugas

1. **[UI/UX-Bot] (Kostum Cyan - Meja Drawing Tablet & Wireframe):**
   - Merancang user journey, wireframe struktur halaman, *design system tokens* (warna, font, spacing), dan verifikasi 10 Heuristik Usability Nielsen.
2. **[FE-Bot] (Kostum Biru - Meja Dual Monitor UI & RGB Keyboard):**
   - Mengubah wireframe menjadi komponen antarmuka nyata (HTML5 semantic, CSS3/Tailwind, JavaScript modern), responsivitas layar, dan komponen interaktif dengan live preview.
3. **[DAILY-Bot] (Kostum Hijau Emerald - Hub Produktivitas & Kalender):**
   - **Asisten Aktivitas Harian & Personal Productivity:**
     - ⏱️ **Interactive Pomodoro Focus Timer:** Mode deep work 25 menit dengan kontrol Start/Pause/Reset.
     - 📝 **Interactive To-Do Checklist:** Daftar prioritas tugas harian kuliah & coding (bisa tambah task baru dan centang selesai).
     - 📅 **Time-Blocking Schedule:** Pembagian jadwal waktu optimal (pagi, siang, sore, malam).
     - 🔥 **Habit Streak Tracker:** Pemantauan konsistensi coding, belajar kuliah, dan hidrasi.
4. **[BE-Bot] (Kostum Jubah Ungu - Konsol Server & Diagram ERD):**
   - Merancang skema relasional database (SQL DDL, indexing, constraints), arsitektur REST API, autentikasi JWT, dan integrasi server.
5. **[SEC-Bot] (Kostum Merah/Emas - Meja Radar 360° & Terminal Hijau):**
   - Spesialis Cyber Security & CTF Solver: Audit celah OWASP Top 10 (SQLi, XSS, CSRF, IDOR), simulator CTF crypto & reverse solver, serta security hardening patch.

## 🎮 Cara Menjalankan & Menyuruh AI Agent Bekerja

1. **Mode Berantai (5-Agent Auto-Pipeline):**
   - Ketik topik proyek atau tugas di kotak input komando, lalu klik **`🚀 LAUNCH AUTO-PIPELINE (5-AGEN)`**.
   - Kelima bot akan berurutan menyusun spesifikasi: UI/UX ➔ Frontend ➔ Daily Productivity ➔ Backend ➔ Cyber Security.
2. **Mode Kerja Mandiri (Solo Dispatch):**
   - Ingin mengerjakan bagian tertentu saja? Klik tombol **`🎨 Suruh UI/UX`**, **`💻 Suruh FE`**, **`📅 Suruh DAILY`**, **`🗄️ Suruh BE`**, atau **`🛡️ Suruh SEC`**.
3. **Kendali Ruangan Manual (Click-to-Move):**
   - Klik karakter di kanvas lalu klik lantai mana saja untuk menggerakkan bot ke titik tersebut.
4. **Download Dokumen Lengkap (.MD):**
   - Klik tombol **`📥 DOWNLOAD LAPORAN LENGKAP (.MD)`** pada tab Mission Summary untuk mengunduh seluruh cetak biru proyek ke komputer.
